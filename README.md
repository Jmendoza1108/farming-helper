# Farming Helper

A Java-based Minecraft Fabric mod focused on crop detection, player movement tracking, and experimental farming automation.

## About the Project

Farming Helper is a personal project I created to improve my Java programming skills through hands-on software development.

Using Minecraft's Fabric API, I'm developing a system that can recognize nearby crops, monitor player movement, and evaluate farming conditions in real time.

This project is currently under development.

## Current Features

- **Toggle System:** Enable and disable the helper using the H key.
- **Runtime Tracking:** Track how long the helper has been enabled.
- **Crop Detection:** Identify nearby crops, including wheat, carrots, potatoes, and other supported crops.
- **Movement Detection:** Track player movement across different directions.
- **Farming State Detection:** Determine when the player is positioned and moving appropriately for farming.
- **Obstacle Detection:** Check for blocks obstructing the current farming direction.
- **Vertical Movement Detection:** Detect downward movement following a detected obstacle.
- **Attack Key Control:** Control the attack input based on farming-state conditions.
